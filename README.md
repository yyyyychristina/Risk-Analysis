# Risk-Analysis

## Overview
This project is an interactive data analytics dashboard designed to evaluate commercial loan risk and identify potential credit issues. It uses data visualization and synthetic dataset modeling to simulate how financial institutions assess borrower risk and portfolio health.

---

## Key Features
- Interactive risk analysis dashboard built in Power BI
- Visualization of key credit risk indicators
- Identification of high-risk loan patterns and anomalies


---

## Data Preparation
- Created synthetic commercial loan dataset using Python (Pandas, NumPy)
- Simulated financial attributes such as:
  - Income levels
  - Loan amounts
  - Debt-to-income ratios
  - Default probability estimates
- Cleaned and structured dataset for dashboard integration

---

## Tools & Technologies
- Python (Pandas, NumPy)
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data visualization techniques
